# Sparrow

A real-time messaging application built as a personal software engineering project.
(Translation: I hate messenger and I'm out of ideas)

## Goal

- improve my (almost non-existent) software engineering skills
- create a real chat application that I can eventually use instead of messenger

## Tech Stack

- TypeScript
- React
- Next.js
- Tailwind CSS
- Supabase
- PostgreSQL

## Planned Features

- User authentication
- 1-to-1 conversations
- Real-time messaging
- Online presence
- Message history
- Image sharing
- Read receipts
- Group conversations

## Status

Currently in development.
